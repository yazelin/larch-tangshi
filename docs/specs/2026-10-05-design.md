# 唐詩系列第一首〈過故人莊〉設計規格

日期：2026-10-05
用途：在 Larch 上做唐詩互動教材，跟同一首詩的影片版放在一起比，證明互動版教得更好。完成後上市集，再拿去寫文章、直播分享。
參考：doggy8088/TangPoetry-guo-guren-zhuang（8 分鐘直式動畫＋網頁，8 場景、52 句旁白、23 個生字、四張圖背誦法）。該 repo 沒有 LICENSE，所以劇本、角色、配音、美術一律不沿用，只參考教學骨架。詩句與讀音屬於公共知識。

## 1. 目標與限制

- 玩家：小學三年級（約 8 歲）。每個生字都有注音和發音。
- 全程 12～15 分鐘。
- 「比影片版好」具體指四件事，驗收時逐條對：
  1. 小朋友要親手操作，不是看完一支影片。
  2. 答錯時劇情會停下來換個方式解釋，再回來重答。
  3. 畫面用插畫 CG，照考證畫出黍、場圃、桑麻、重陽。影片版（https://youtu.be/5v1CiE1r70E ）的角色與場景是用程式畫的 SVG 與 CSS 圖形，做得很乾淨，但畫不出這些細節。
  4. 背誦做成可以玩的關卡，並且會先複習答錯過的字。
- 範圍：只做完這一首。劇本格式和插件卡要讓下一首詩只換資料就能套用，但這次不規劃其他首。
- 不在範圍內：原版和 Larch 版的對照展示頁（上市集之後另外做）。

## 2. 系列設定

- 兩個現代小三生會掉進詩的世界，每一首詩是一個世界。這次掉進唐朝，陪孟浩然走完這趟拜訪。
- 主角暫名「阿禾」（急性子）和「小樂」（愛問問題），名字和性別在寫 `canon/系列角色.md` 時定案，之後整個系列沿用。
- 主角穿現代童裝，到了唐朝也不換，一眼看得出是外來的。
- 唐朝這邊的角色：孟浩然、故人（田家主人）。
- 故事目的是帶小朋友親眼看唐代田家：黍是什麼、桑和麻拿來做什麼、重陽為什麼賞菊。所有說法以 `poems/guo-guren-zhuang/考證.md` 為準。

## 3. 流程

```
0 開場：掉進詩卷
1 故人具雞黍，邀我至田家    （收到邀請、認識黍）
2 綠樹村邊合，青山郭外斜    （走到村子）
3 開軒面場圃，把酒話桑麻    （進屋、開窗、聊農事）
4 待到重陽日，還來就菊花    （約好重陽再來）
5 收尾：四張圖排順序 → 複習答錯的字 → 背誦三關 → 學會幾個字 → 回到現代
```

第 1～4 幕的節奏都一樣：先演故事，遇到生字就出生字卡，最後用「跟著念」把這兩句念一遍。

每一條路徑都要走得到結局，答錯不會卡住。

## 4. 唐詩插件 tangshi-kit

一個插件，四種卡。卡片內容（字、注音、圖、音檔、選項）全部從卡片參數傳進去，插件裡不寫死任何一首詩。

| 卡 | 行為 | 回傳 |
|---|---|---|
| 生字卡 | 楷體大字＋注音，點字播發音。下方三張圖選意思，選對翻面看解釋 | `correct` / `wrong` |
| 生字卡（只看） | 同上，但不出題，點了聽、看了就過 | `done` |
| 跟著念 | 一行五字照配音節奏逐字點亮，每字可單獨點來聽 | `done` |
| 四張圖排順序 | 四張 CG 打亂，拖成正確順序，每張附兩句詩 | `done`（排對才放行） |
| 背誦闖關 | 三關：遮 1/3、遮 2/3、全遮，從字塊挑字補回去，結算星星 | 星星數 |

- 生字卡答錯：劇情分支出去，由角色換個說法解釋，再回到同一張卡重答。
- 錯誤選項的圖從其他生字的圖裡抽，不另外產。
- Larch 插件卡拿不到麥克風，背誦只能挑字，不做念出聲辨識。
- 核心字（出題）約 12 個，初稿：雞黍、邀、合、郭、斜、軒、場圃、把、話、桑麻、重陽、就。寫劇本時定案。其餘生字走「只看」。

### 變數

- 每個核心字一個變數，記第一次有沒有答對。
- 進背誦前，對每個第一次答錯的字再出一次生字卡。
- 結尾顯示學會的字數。
- 插件變數閘門要列出所有會寫入的變數名（少列會被靜默丟掉）。

## 5. 美術

- 畫風：水彩繪本，暖色調唐代田園。
- 素材：
  - 角色立繪 4 人（阿禾、小樂、孟浩然、故人），每人 3～4 個表情。兩個主角的定錨圖這次做好，系列共用。
  - 場景背景約 5 張：詩卷書房、田家門口、村路、屋內、菊花籬笆。
  - 劇情 CG 約 6 張，其中 4 張就是「四張圖」。
  - 生字小圖約 23 張，一字一張。
- 產線規矩：
  - 繪圖只用本機 codex 或 .11 codex-image。
  - CG 一律帶在場角色定錨。
  - 出圖過檢查器，只把需要作者拍板的圖給作者看。
- 素材放這個 repo 的 `poems/guo-guren-zhuang/art/` 與 `canon/角色/`，不混進其他作品的素材庫。
- 畫面內容照 `考證.md`：例如黍畫成黃色小米粒，不能畫成稻米。

## 6. 配音

- 用 Larch 配音，並行數寫死 3。
- 破音字用同音字替身：斜→霞（xiá）、郭→鍋（guō）、還→孩（hái）。畫面顯示原字，配音送替身字。
- 配完用語音轉文字比對讀音；斜、郭、還三個字由人工逐個聽過。

## 7. repo 與工程

repo：`yazelin/larch-tangshi`，公開。

```
canon/系列角色.md            兩個主角設定（跨詩共用）
```

- 推上 Larch 前一定先抓快照；推完比對卡數。發佈由作者在網頁按。

## 8. 驗收

- 靜態檢查 `tests/check_static.py`：
  - 23 個生字全部出現。
  - 每張生字卡都有音檔和圖。
  - 插件變數閘門列的名字和實際寫入的一致。
  - 劇本裡的詩句和正典一字不差。
  - 每張卡都走得到結局。
- 全路徑試玩（Playwright，三條）：
  1. 全部答對。
  2. 每個核心字都先答錯一次：要看到解釋分支，也要看到背誦前的複習段。
  3. 背誦三關全過，結尾字數正確。
- 讀音：生字音檔轉文字比對，三個破音字人工聽。
- 第 1 節列的四件事，逐條在試玩錄影裡找得到。
